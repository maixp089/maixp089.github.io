プライバシーポリシー

制定日：2026年10月31日

このポリシーは、個人が家族のために運用している非商用の LINE チャットボット「orbit-minion（まゆ）」（以下「本サービス」）が扱う情報について説明します。本サービスの利用者は運用者の家族に限られます。

1. 取り扱う情報

  • LINE のユーザーID・グループID、本サービス宛てに送られたメッセージ（本サービスへのメンションを含むもの、1対1のトーク）、および利用者が解析を依頼した画像・PDF
  • 家族で共有する Google カレンダーの予定（タイトル、日時、場所、メモ）

メンションのない通常の会話や、解析を依頼されていない画像は取得・保存しません。

2. 利用目的

予定の読み取り、Google カレンダーへの登録・検索・変更・削除、リマインドの送信のためにのみ利用します。広告、販売、第三者への提供には利用しません。

3. Google ユーザーデータの取り扱い

本サービスは、家族カレンダー専用の Google アカウントが所有するカレンダーの予定にのみアクセスします（スコープ：calendar.events.owned）。Google API から取得した情報の利用は、Google API Services User Data Policy（Limited Use の要件を含む）に従います。取得した情報を AI モデルの学習に使用したり、第三者に譲渡・販売したりすることはありません。

4. 処理と保存の場所

  • Amazon Web Services（東京・大阪リージョン）：メッセージの処理、AI モデル（Amazon Bedrock）による内容の読み取り、画像の一時保存
  • Neon（AWS シンガポールリージョン）：家族・予定・リマインドの管理データ
  • Google カレンダー：予定そのもの
  • LINE：メッセージの送受信

5. 保存期間と削除

情報は本サービスの提供に必要な期間だけ保存し、不要になったものは削除します。利用者から削除の依頼があった場合は、速やかに対応します。
